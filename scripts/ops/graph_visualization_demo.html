💻 Cypher 查詢示例

以下是生成上述圖譜的 Cypher 查詢:

MATCH (source) WHERE source.name IN ["Leonardo da Vinci", "Mona Lisa"] OR source.title IN ["Leonardo da Vinci", "Mona Lisa"] OPTIONAL MATCH path = (source)-[r*1..2]-(related) WITH source, relationships(path) as rels UNWIND rels as rel WITH DISTINCT source, rel, startNode(rel) as start, endNode(rel) as end RETURN collect(DISTINCT { id: id(source), label: labels(source)[0], name: coalesce(source.name, source.title, '未知') }) as source_nodes, collect(DISTINCT { id: id(start), label: labels(start)[0], name: coalesce(start.name, start.title, '未知') }) as all_nodes, collect(DISTINCT { source: id(start), target: id(end), relationship: type(rel) }) as edges

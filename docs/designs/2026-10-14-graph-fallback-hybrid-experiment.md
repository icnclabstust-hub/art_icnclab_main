# 第 2 層改動實驗評估表：graph 錨點查無時，非事實題改退回 hybrid（規格 Q2）

> 範本：`docs/templates/LAYER2_EXPERIMENT_ASSESSMENT.md`。風險 Tier B（改變 graph 路由非事實題的檢索），**須指導老師核可才可上 8001**。
> 使用者 2026-10-14 同意改為 hybrid（待老師核可）。

## 一、變更描述
- 改了什麼：graph 路由在錨點查無（認不出畫家）或模板 0 列時，非事實題的退回路由由 fulltext 改為 hybrid（向量＋BM25＋圖的系統級 RRF）。事實題仍退回 vector。
- 影響哪些查詢：只有選 `graph` 路由、且錨點查無的非事實題（理論題、部分限制條件題）；錨點命中的題（關係題全部、理論題 8／15）不受影響。所有模型。
- feature flag：`GRAPH_FALLBACK_NONFACT`，預設 `fulltext`（現行行為）；上線值 `hybrid`。開關併入快取鍵（`:gf=`）。hybrid 內部呼叫 graph 時帶 `fallback=False`，不會遞迴。

## 二、假設
- 預期變好：詞典翻譯（8080 輪換模型時的常態）＋空殼過濾後，fulltext 對理論題常 0 筆來源；hybrid 有向量路可補。
- 可能變差：hybrid 混入向量結果，可能帶進語意相近但不精確的文件；矛盾主張數 E9 略多（見 §三）。
